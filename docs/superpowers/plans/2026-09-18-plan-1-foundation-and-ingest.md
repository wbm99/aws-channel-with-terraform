# Foundation and Ingest Spike Implementation Plan (Plan 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the repo foundation (state bucket, budget guardrails) and prove that an SRT-listener MediaConnect flow can be created, receive an FFmpeg SRT stream, and be destroyed cleanly using the `awscc` provider.

**Architecture:** A one-time `bootstrap/` root creates the S3 state bucket. `modules/guardrails` and `modules/ingest` are wired together in `envs/demo`. The ingest module uses `awscc_mediaconnect_flow` (the `hashicorp/aws` provider has no MediaConnect flow resource) plus a Terraform-generated SRT passphrase in Secrets Manager.

**Tech Stack:** Terraform >= 1.11, providers `hashicorp/aws ~> 6.0`, `hashicorp/awscc`, `hashicorp/random`; FFmpeg; AWS CLI v2.

**Spec:** `docs/superpowers/specs/2026-09-18-live-srt-pipeline-design.md`

## Roadmap

- **Plan 1 (this plan):** foundation and ingest spike.
- **Plan 2:** encode (MediaLive), package (MediaPackage v1), delivery (CloudFront), player. Written after Plan 1's spike result is known.
- **Plan 3:** Python CLI (`start`/`stop`/`status`/`check-clean`), FFmpeg source script, end-to-end demo, README.

## Global Constraints

- Region: `us-east-1`.
- Terraform `required_version = ">= 1.11"`; remote state in S3 with native locking (`use_lockfile = true`), no DynamoDB.
- Budget: $25 monthly; alerts at 50% and 80% (actual) and 100% (forecast), by email.
- SRT passphrase is generated by Terraform, stored in Secrets Manager, and never hardcoded or committed.
- The SRT listener only accepts a configured source CIDR; `0.0.0.0/0` is rejected.
- Every module has `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf`; providers pinned; resources tagged `Project` and `Env`.
- Follow the `terraform-style-guide` skill (2-space indent, `terraform fmt`, snake_case, descriptions and types on all variables and outputs).
- Tests use `terraform test` with `mock_provider`, `command = plan`, and need no AWS credentials.
- Layout note: Terraform runs tests from the module directory, so tests live in `<module>/tests/`, not a repo-root `tests/` (this refines the spec's layout).

    { threshold = 80, type = "ACTUAL" },

  ]

resource "aws_budgets_budget" "monthly" {

  budget_type  = "COST"

      threshold                  = notification.value.threshold
      threshold_type             = "PERCENTAGE"
      notification_type          = notification.value.type

    }
  }
}

`modules/ingest/main.tf`:

```hcl
resource "random_password" "srt" {
  length  = 32
  special = false
}

resource "aws_secretsmanager_secret" "srt" {
  name                    = "${var.name}-srt-passphrase"
  recovery_window_in_days = 0
}

resource "aws_secretsmanager_secret_version" "srt" {
  secret_id     = aws_secretsmanager_secret.srt.id
  secret_string = random_password.srt.result
}

data "aws_iam_policy_document" "assume" {
  statement {
    actions = ["sts:AssumeRole"]

    principals {
      type        = "Service"
      identifiers = ["mediaconnect.amazonaws.com"]
    }
  }
}

data "aws_iam_policy_document" "read_secret" {
  statement {
    actions   = ["secretsmanager:GetSecretValue"]
    resources = [aws_secretsmanager_secret.srt.arn]
  }
}

resource "aws_iam_role" "flow" {
  name               = "${var.name}-mediaconnect"
  assume_role_policy = data.aws_iam_policy_document.assume.json
}

resource "aws_iam_role_policy" "read_secret" {
  name   = "read-srt-passphrase"
  role   = aws_iam_role.flow.id
  policy = data.aws_iam_policy_document.read_secret.json
}

resource "awscc_mediaconnect_flow" "this" {
  name = var.name

  source = {
    name           = "${var.name}-srt"
    protocol       = "srt-listener"
    ingest_port    = var.ingest_port
    whitelist_cidr = var.whitelist_cidr
    min_latency    = var.min_latency_ms

    decryption = {
      algorithm  = "aes256"
      key_type   = "srt-password"
      role_arn   = aws_iam_role.flow.arn
      secret_arn = aws_secretsmanager_secret.srt.arn
    }
  }

  depends_on = [
    aws_iam_role_policy.read_secret,
    aws_secretsmanager_secret_version.srt,
  ]
}
```
