# ABR Ladder, CloudFront Delivery and Player Implementation Plan (Plan 3 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the working spike into the full viewer path: a 3-rung ABR ladder from MediaLive, MediaPackage v2 locked behind CDN authorization, a CloudFront distribution, and a static player page (hls.js) with a latency overlay, all declarative.

**Architecture:** `modules/encode` takes a `renditions` list and builds video descriptions and outputs with `dynamic` blocks. `modules/package` replaces the spike's public-read endpoint policy with header-based CDN authorization (secret, role, policy condition). `modules/player` holds a private S3 bucket with the static page. `modules/delivery` is one CloudFront distribution with two origins: the player bucket (default behavior, OAC) and MediaPackage (`/out/*`, custom origin with the CDN-identifier header).

**Tech Stack:** Terraform >= 1.11; providers `hashicorp/aws ~> 6.0`, `hashicorp/awscc ~> 1.0`, `hashicorp/random ~> 3.6`; hls.js 1.5.15 (from jsDelivr); FFmpeg; AWS CLI v2.

**Spec:** `docs/superpowers/specs/2026-09-18-live-srt-pipeline-design.md`

## Roadmap

- Plans 1-2: done (foundation, ingest, thumbnails, delivery-path spike).
- **Plan 3 (this plan):** ladder, CDN authorization, CloudFront, player.
- Plan 4: Python CLI, FFmpeg source script, end-to-end demo, cost estimate, README.

## Global Constraints

- Region: `us-east-1`. Terraform `required_version = ">= 1.11"`; remote state in S3 with native locking.
- Ladder default: 1080p (5 Mbps), 720p (3 Mbps), 480p (1.5 Mbps), 30 fps, 2 s GOP, plus one AAC 128 kbps audio track; 6 s HLS segments. The ladder is a variable, not hard-coded.
- Delivery is TS/HLS through MediaPackage v2 (`input_type = "HLS"`, `container_type = "TS"`), as proven in Plan 2.
- MediaPackage must NOT be publicly readable: playback requires the `X-MediaPackageV2-CDNIdentifier` header. The spike's public-read policy is removed.
- The CDN identifier is generated by Terraform (`random_uuid`), stored in Secrets Manager as JSON key `MediaPackageV2CDNIdentifier`, and marked `sensitive` where output.
- `channel_class` stays a variable defaulting to `SINGLE_PIPELINE`; `start_channel = false`; channel and flow are started and stopped with the AWS CLI (Plan 4 wraps this in Python).
- Everything declarative: no `terraform_data`, `local-exec` or CLI-created resources.
- Every module has `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf`; providers pinned; follow the `terraform-style-guide` skill; tests use `terraform test` with `mock_provider` in `<module>/tests/`.
- The live run is short and ends with `terraform destroy` and a leftover check. CloudFront create and destroy each take several minutes.

```hcl
resource "random_uuid" "cdn_identifier" {}

resource "aws_secretsmanager_secret" "cdn" {
  name                    = "MediaPackageV2/${var.name}-cdn-auth"
  recovery_window_in_days = 0
}

resource "aws_secretsmanager_secret_version" "cdn" {
  secret_id = aws_secretsmanager_secret.cdn.id

  secret_string = jsonencode({
    MediaPackageV2CDNIdentifier = random_uuid.cdn_identifier.result
  })
}

resource "aws_iam_role" "cdn_auth" {
  name = "${var.name}-mediapackage-cdn-auth"

  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect    = "Allow"
        Action    = "sts:AssumeRole"
        Principal = { Service = "mediapackagev2.amazonaws.com" }
      }
    ]
  })
}

resource "aws_iam_role_policy" "cdn_auth" {
  name = "read-cdn-secret"
  role = aws_iam_role.cdn_auth.id

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect   = "Allow"
        Action   = ["secretsmanager:GetSecretValue", "secretsmanager:DescribeSecret"]
        Resource = aws_secretsmanager_secret.cdn.arn
      },
      {
        Effect   = "Allow"
        Action   = ["secretsmanager:BatchGetSecretValue"]
        Resource = "*"
      },
    ]
  })
}

resource "awscc_mediapackagev2_origin_endpoint_policy" "playback" {
  channel_group_name   = awscc_mediapackagev2_channel_group.this.channel_group_name
  channel_name         = awscc_mediapackagev2_channel.this.channel_name
  origin_endpoint_name = awscc_mediapackagev2_origin_endpoint.hls.origin_endpoint_name

  cdn_auth_configuration = {
    cdn_identifier_secret_arns = [aws_secretsmanager_secret.cdn.arn]
    secrets_role_arn           = aws_iam_role.cdn_auth.arn
  }

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Sid       = "AllowGetObjectForAuthorizedRequests"
        Effect    = "Allow"
        Principal = "*"
        Action    = "mediapackagev2:GetObject"
        Resource  = awscc_mediapackagev2_origin_endpoint.hls.arn

        Condition = {
          Bool = {
            "mediapackagev2:RequestHasMatchingCdnAuthHeader" = "true"
          }
        }
      }
    ]
  })

  depends_on = [
    aws_iam_role_policy.cdn_auth,
    aws_secretsmanager_secret_version.cdn,
  ]
}
```
